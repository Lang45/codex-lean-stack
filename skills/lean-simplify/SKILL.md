# Codex 主任务精简

## 职责与触发

本入口决定非平凡主任务需要哪些步骤、做到什么范围和何时停止；与 `$lean-stack` 子代理调用平行、
独立且互不前置。调查、实现、测试、复核、发布或文档维护命中本入口；无需工具的一次性答复和
单个确定性工具动作直接完成。`$lean-stack` 独立判断委派，任何一方都不等待、阻断或代证另一方。

新项目或新会话不无条件读取两个入口。非平凡主任务命中时才读取已加载目录中的本 `SKILL.md`；
已读且入口未变化时直接复用。只读取并应用当前实际动作命中的入口，不预读 `$lean-stack` 或完整
`references`。本入口与其他适用技能的用途说明合并到唯一启动说明；读取后的下一次工具调用
立即开始实际任务，不插入第二段前言、无关扫描或版本解释。

本入口是提示驱动合同，不是宿主 Hook、后台服务或权限来源。修改、外部操作、创建任务和不可逆
影响仍以用户当前要求与更高层规则为准；始终保留安全、权限、数据完整性和诚实证据边界。
工具与 PowerShell 路径精简共同遵守
[Windows exec 稳健性契约](../lean-stack/references/windows-exec.md#windows-exec-与-powershell)。

## 最小完整方法

先理解真实调用流、用户可见结果和受保护边界，再选择第一个完整满足要求的选项：

1. 不实现当前要求不需要的行为；
2. 复用现有工具、类型、约定或帮助函数；
3. 优先标准库、平台原生能力、官方支持的扩展点、项目已有适用依赖，以及维护、安全、许可和
   兼容性可接受的成熟开源库；
4. 优先删除、内联、合并或一个聚焦改动；
5. 前述均不满足时才增加最少的新代码和文件。

当前目标始终从最早一个尚未完成，或已经完成但尚未通过用户可见回复交付的有效要求继续；新要求
只调整受影响范围，不挤掉其他活动项。已交付事项退出活动清单，不复活未受影响的历史。动手前
写清要改变的行为、必须保持的行为，以及
哪一个最窄检查能区分对错；不预造用户未要求的产物、复核、升版、安装或发布。

不能为少代码或少步骤删掉用户要求、错误处理、可访问性、安全、隐私、权限、数据完整性、真实
外部系统的不确定性处理或能捕获非平凡回归的低成本检查。完成条件来自用户可见结果；只读、方案、
暂停和审阅按指定边界停止，源码、静态文字、编译或子代理自报不能冒充真实运行。

## 可选准备动作触发器

父代理已经理解目标，却准备执行一个不能直接产生首个可验证主任务结果、也不能解除已命名阻断的
可选准备动作时，及时应用本入口一次，只回答“当前代码、证据和授权内，哪条最短路径能产生首个
可验证结果”，随后立即执行第一项实际动作。

第一条说明给出当前理解、立即动作和必要限制，并合并本轮其他技能用途；不再为每个入口或分支
重复前言，也不重复发两份前言。能直接答完的请求由最终答案本身完成。

新会话额外预读或前言、目标与验收未定前的批量编辑、决定性验收通过后的同类复验都命中；正在
运行的必要工具、唯一权威读取、权限或安全检查和解除已命名阻断的动作不命中。本触发器不计时、
不创建脚本、Hook、持久状态或新子代理，也不得延后 `$lean-stack`。

过程中只报告会改变后续动作的进展；不以重复前言、纯确认或准备说明阻塞首个可验证结果。
同一根因的首次决定性失败后先修真实根因，再做一次能区分修复前后的复验；目标条件已覆盖就
停止。新证据、依赖、公共约定或风险范围变化时才扩大检查。

## 条件路由

按当前状态和下一项实际动作判断，不按用户是否写出条件名称判断。入口先完成快速判断，只保留会
改变下一动作的目标、步骤、风险、验证和停止条件；确认命中具体功能分支后，才读取其最小权威
段落。未命中分支不读取，也不批量预读可能稍后使用的分支。分支读取不再产生第二段技能用途说明；
读取后下一次工具调用执行该分支的实际操作。同一任务可以随实际动作依次命中多个分支；每个分支
在真正开始对应动作时读取，不能预先成批加载，也不能因拆分而跳过后继触发。

| 条件 | 权威入口 |
| --- | --- |
| 准备查明未知事实、现状、调用链或原因，尚不修改 | [调查](../lean-stack/references/investigation.md) |
| 已有错误、失败或可复现症状，准备建立反馈、定位并修复 | [缺陷修复](../lean-stack/references/bug-fix.md) |
| 准备新增或修改实现，或在没有待修失败时重构 | [构建](../lean-stack/references/build.md) |
| 准备判断需求符合度、工程质量、风险或是否适合合并 | [审查](../lean-stack/references/review.md) |
| 后续有两个或更多必须按顺序完成、前一步会解锁后一步的阶段 | [长任务](../lean-stack/references/long-running.md) |
| 下一步要编写 Windows exec、PowerShell、复杂参数或任务脚本 | [Windows exec 与 PowerShell](../lean-stack/references/windows-exec.md) |
| 准备确定检查对象、独立预期或验证范围，或执行条件性验证或最窄重验 | [条件性验证](../lean-stack/references/verification.md) |
| 准备新增抽象、兼容层、流程或文件，或需要证明现实消费者 | [反 AI 过度工程](../lean-stack/references/anti-overengineering.md) |
| 用户明确要求执行正式消融，而不只是普通精简 | [消融反馈循环](../lean-stack/references/ablation-loop.md) |
| 已获授权且下一步确实要升版、安装、发布或维护发布文档 | [版本与发布](../lean-stack/references/versioning.md) |
| 只需解释现有执行链，不执行上述动作 | [中文链路图](../lean-stack/references/flowcharts-zh.md) |

测试只运行与当前改动、风险和用户要求相称的最窄检查；安全、权限、数据完整性、外部副作用或公共
合同风险所需检查不得省略。来源与风险未变时复用通过证据；失败只修真实根因并重跑失败项与受
影响项。迭代中的工具/子代理路线属于 `$lean-stack`，本入口只确定测什么、预期和停止条件。

静态合同只能证明公开文字与链接；正式安装后的新会话行为必须依赖正式缓存、独立任务和真实宿主
事件取证，不能由当前源码读取、静态测试或手工加载候选文本代替。
