# 子代理委派兼容索引

本文件只兼容旧链接，不再承载普通派发、配置声明、来源读取、结果汇合和保留生命周期的重复
细则。先由 [lean-stack 入口](../SKILL.md)决定是否委派；决定未通过时继续主任务，不读取本文件，
也不以 `status --for-routing`、`recall` 或创建任务类型组作为前置证明。

| 已确认动作 | 直接读取 |
| --- | --- |
| 首次派发、模型和思考程度、任务卡、原生参数 | [首次派发执行分支](dispatch-start.md) |
| 长来源、来源所有权、覆盖范围和结果复用 | [来源所有权与结果收据](source-results.md) |
| 任务类型组、复制、变体、竞争、否定后重做 | [任务类型组、复制与变体](agent-groups.md) |
| 关键步骤消息、最终提交、父代理汇合与停止 | [子代理结果与汇合](agent-results.md) |
| 可写并行与精确撤销 | [可写子代理并行](write-parallelism.md) |
| 协作父代理与其他 Codex 任务 | [协作父代理](collaboration.md) |
| TOML、经验、迁移、CAS 或永久删除 | [全局领域保留子代理经验](specialist-memory.md) |

已经决定调用后，按首次派发分支匹配轻量路由目录；失败立即使用合规运行时子代理，不重试、不
扩大搜索，也不把查询变成调用前置。插件本身不授予跨任务读写、消息或创建权限；`create_thread` 仅在用户明确要求创建
新任务时使用，其他跨任务动作也必须落在当前用户要求或授权的准确范围内。

旧链接命中本页后直接选择当前动作对应的小分支；后继动作可继续命中其他分支，但不要把索引与
全部分支预先一起载入。
