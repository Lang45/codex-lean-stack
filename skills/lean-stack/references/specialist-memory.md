# 可选专门代理记忆

仅在稳定重复角色值得创建或安全重配、胜出结果有可复用经验，或者一个插件精确拥有
的专门代理必须永久删除时读取。任何一项都不能进入普通分派热路径。

当主任务基于稳定重复的工作类型、已验证结果和明确未来用途，判断角色确实值得未来复用
时，自动授权插件拥有的非破坏性创建、安全重配、胜出经验去敏追加和摘要压缩；用户
明确否决时不得执行。自动授权不覆盖永久删除，也不允许保存当前提示、源码、路径、
网址、日志、凭据或一次性任务事实。

维护只能与父任务仍需完成的真实主任务工作并行。主结果先准备好时，立即放弃维护；
终止条件满足后不得再启动或等待维护。

辅助脚本是 [agents.py](../scripts/agents.py)，只有 `ensure`、`improve` 和 `delete`
三个命令。任何数据库、文件、结构、锁或宿主可见性失败都返回
`auxiliary_skipped`，不能拖延真实任务。

## 每类角色只保留一个

只有专长稳定、重复且有明确未来用途时才使用 `ensure`；“值得复用”的判断即提供这项
非破坏性自动授权。不得写入当前提示、仓库、网址、日志、凭据或一次性任务：

```powershell
py -3 .\skills\lean-stack\scripts\agents.py ensure `
  --role-key qml-binding-diagnostics `
  --display-name "绑定诊断员" `
  --description "重复诊断绑定循环、依赖失效和运行时警告。" `
  --instructions "追踪实际绑定依赖，返回可复核根因和最小处理。" `
  --model gpt-5.6-terra `
  --reasoning-effort high `
  --authority read
```

行为如下：

- 没有匹配角色：创建一个插件拥有的代理配置，供未来新任务使用；
- 配置完全相同：复用；
- 配置不同：不写入，返回 `reconfiguration_required`；
- 已验证胜出配置：使用返回的 `--expected-sha256 <当前哈希>` 再执行同一命令；
- 安全重配保留代理身份、路径、所有权令牌、原始经验和压缩摘要，并返回
  `host_visibility=requires_new_task`；
- 看似受管但没有可信台账记录的同角色文件会阻止创建，不能擅自接管、删除或复制。

新建或重配的代理不假定能在当前任务热加载。当前任务继续使用已经可见的通用或定制
代理，不轮询、不重新加载、不重启。

## 只保留有用经验

角色值得未来复用且结果已验证胜出时，自动授权追加一条提炼、去敏、可复用的经验：

```powershell
py -3 .\skills\lean-stack\scripts\agents.py improve `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --event-id <唯一标识> `
  --lesson "可复用且有证据支持的经验"
```

原始事件只追加且没有总数量上限。不得记录坏结果、原始提示、源码、仓库路径、网址、
日志、凭据或模型思维过程。每次更新只读取一个有界待处理窗口，较早原始记录保留在
数据库中等待以后增量压缩。

返回 `compaction.needed=true` 时，只有完整路线仍符合当前工作价值排序，才让合格且
成本较低的子代理在父任务继续真实工作时压缩旧摘要和增量事件。提交摘要：

```powershell
py -3 .\skills\lean-stack\scripts\agents.py improve `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --summary "压缩后的可复用摘要" `
  --covered-through <序号> `
  --source-digest <摘要来源哈希>
```

来源哈希和序号是比较并交换保护。刷新摘要永不删除或截断原始事件。若压缩会拖慢主
任务，直接推迟。

## 永久删除

运行时复制和变体随任务结束，不需要清理。只有用户当前明确要求永久删除时，才删除
持久专门代理。`severe_bad`、用户否定结果、未授权影响或伪造证据只能触发停止采用、
阻止继续使用、报告风险和提出删除建议，不能替代删除授权：

```powershell
py -3 .\skills\lean-stack\scripts\agents.py delete `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --owner-token <所有权令牌>
```

删除要求台账记录、直接普通配置路径、单一硬链接、受管标记、名称、所有权令牌和
文件哈希全部匹配。缺失文件的台账清理也要求同一哈希和令牌。没有隔离、恢复或状态机。
辅助脚本在真正删除前再次核对路径；仍存在同权限进程恰在最后操作间隙替换文件的残余
边界，因此删除不能与另一个代理目录写入者并行。

## 数据库边界

独立数据库位于：

```text
<CODEX_HOME>/lean-stack/specialist-memory-v1.sqlite3
```

它只保存专门代理所有权、只追加经验和摘要，从不打开、迁移或删除旧生命周期数据库
或旧隔离数据。只有版本为零且没有用户对象时才初始化新结构。未知版本、意外表、
视图、触发器、命名索引、列结构、主键或唯一索引、外键、忙锁、损坏或不可用文件都
会让辅助命令关闭，但主任务继续。
