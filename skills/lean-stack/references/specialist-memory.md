# 保留子代理经验

专门代理记忆就是经验。仅在已验证并被采用的任务类型组需要创建或安全重配保留子代理、结果
需要追加可复用经验，或者一个插件精确拥有的候选需要可恢复退役或恢复时读取。运行时先复用
适合的任务类型组和可见保留子代理；没有可见保留子代理或需要新组时，由父代理定制运行时
新子代理完成真实任务。创建、安全重配和经验维护只是结果出来后的非阻塞持久侧支，任何
一项都不能进入普通分派热路径或成为当前调用门槛。

每个不同任务类型组的唯一子代理或唯一胜者，其结果通过必要核验并被父代理采用后，第一次
成功就默认跨任务保留，不要求此前已经重复、额外证明未来用途、等待主任务接近结束或等待
并行窗口。这个事实自动授权插件拥有的非破坏性创建、安全重配、一次去敏经验追加和经验摘要
压缩；用户明确否决时不得执行。自动授权不覆盖不可恢复的物理销毁，也不允许保存当前提示、源码、
仓库、路径、网址、日志、凭据或一次性任务事实。

默认提交只有明确排除项：结果未通过核验或未被采用；用户明确否定；角色或经验无法安全
去除上述一次性或敏感内容；权限、安全、SQLite、文件结构、忙锁、损坏、身份或 CAS 使本次
短写不能立即安全完成。没有空闲容量、准备未赶上、没有剩余收口工作或主任务已经满足，不是
取消默认有界尝试的理由。每次失败都立即辅助跳过，不排队、不轮询、不重试，主任务继续。

跨任务保留与经验维护使用两个不同边界：

- 子代理交付可采用结果、父代理仍要运行主任务测试或集成时，有空闲容量可先启动一个低成本、
  只读、步骤有限的经验准备子代理，整理通用角色和去敏经验候选；父代理同时继续测试，不等
  它。准备子代理不写 SQLite，只是提前优化；没有准备或准备未赶上不影响正式提交。
- 跨任务保留在唯一子代理确定、结果核验采用后只尝试一次 `ensure`。这是确定性的短本地写入；
  锁、结构、文件或写入不能立即满足时跳过，不排队、不轮询、不重试。
- 原始经验追加紧接着默认只尝试一次 `improve`。父代理把本组胜出方法和失败避免信息去敏、
  去重后合并成一条新增经验，提前生成稳定 `event_id`，同一候选重放时复用该 ID。没有任何
  新增可复用内容时明确报告原因，不伪造经验。
- 摘要压缩仍只在能与真实工作并行且不争用时执行；不能并行时只推迟摘要，不能取消已经完成
  的原始经验追加，也不能延迟主任务交付。

内部消息不是 SQLite 字段或可臆造的 MCP 工具。自定义角色 TOML 不能替父会话启用协作；
保留 TOML 使用 `[skills] include_instructions = false`，只缩小窄角色上下文。父代理在启动前
验证配置、身份、哈希、父会话 `agents.enabled` 和实际 Luna 模型目录的
`multi_agent_version=v2`。新任务仍须收到真实内部消息才算可用。目录仍为 v1 或直接调用失败时，
中途交流依赖型子任务立即停止；不能升级模型、增加成本或用跨任务 API 冒充。成功轮次仍归
原保留身份，不另建角色。

主任务不依赖任何持久写入成功。

复制、变体、配置比较和经验转移直接决定 SQLite 归属，但不扩张数据库对象，也不决定
当前是否调用子代理：

1. 复制的是任务类型组里的子代理，只处理同一任务类型的额外子任务；普通复制和变体都是
   运行时调用，本身不写入 SQLite 台账。复用保留子代理及普通复制时，由子代理读取自己
   配置中的已有经验。
2. 每个子代理完成当前子任务并按父代理指定的成功条件自检后，立即在自己的线程用最终回复
   提交自己的精炼结果；父代理分别核验和使用，不由子代理预先合并，也不是只选一个。
3. 只有复制前确认保留子代理确有进步空间时，父代理才根据任务类型联合选择完整的模型、
   思考程度和速度组合形成变体；三个字段可以因相互制约而同时变化。只要出现复制或变体，
   组内当前已就绪结果完成必要核验后就竞争，先选出唯一留下的胜者；竞争不让子代理自行决定
   配置，也不删除、延迟或替换已经各自提交的合格结果。单轴变化只在明确需要识别因果时作为
   可选实验。没有复制或变体时，原本唯一子代理直接进入下一步跨任务保留判断。
4. 不同任务类型组第一次成功且结果核验采用后就默认创建记录；已有记录且胜出配置不同时，用当前哈希保护重配
   同一条记录，不为胜者新增第二条同任务类型记录。
5. 跨任务保留完成或安全跳过后，把胜出方法和其他调用中的失败避免信息去敏、去重，默认合并为
   一条新增经验，只追加给
   保留子代理。
6. 经验维护完成或跳过后，其他运行时调用才移出组、结束并从运行时候选中消除；同一任务
   类型组和 SQLite 中都只剩一个保留子代理。

辅助脚本是 [agents.py](../scripts/agents.py)，提供 `status`、`ensure`、`record-run`、
`improve`、`delete` 和 `restore`。这些是按需能力，不是固定顺序、固定数量或固定生命周期；父代理可以
使用其中一个，也可以全部不使用。任何数据库、文件、结构、锁或运行环境可见性失败都返回
`auxiliary_skipped`，不能拖延真实任务。

## 每个任务类型组只保留一个，多个组可以同时保留

各子任务的真实结果和必要核验完成并选出唯一子代理后，只要结果已被父代理采用且未命中明确
排除项，第一次成功就默认使用一次 `ensure`；该事实即提供这项非破坏性自动授权。一次性或
敏感内容无法安全去除、未通过、未采用和被用户否定的子代理不保留。不得写入当前提示、源码、
仓库、路径、网址、日志、凭据或一次性任务：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py ensure `
  --role-key qml-binding-diagnostics `
  --display-name "绑定诊断员" `
  --description "重复诊断绑定循环、依赖失效和运行时警告。" `
  --instructions "追踪实际绑定依赖，返回可复核根因和最小处理。" `
  --model gpt-5.6-terra `
  --reasoning-effort high `
  --speed standard `
  --authority read
```

行为如下：

- 没有匹配任务类型：创建一个插件拥有的保留子代理配置，供未来新任务使用；
- 配置完全相同：复用；
- 配置不同：不写入，返回 `reconfiguration_required`；
- `--speed standard` 不写快速配置；`--speed fast` 写入官方 `service_tier = "fast"` 和
  `[features].fast_mode = true`；经验重写保留该设置，部分或矛盾配置安全拒绝；
- 已验证胜出配置：使用返回的 `--expected-sha256 <当前哈希>` 再执行同一命令；
- 安全重配保留子代理身份、路径、所有权令牌、原始经验和压缩摘要，并返回
  `host_visibility=requires_new_task`；
- 看似受管但没有可信台账记录的同任务类型文件会阻止创建，不能擅自接管、删除或复制。

新建或重配的持久代理不假定能在当前任务热加载。当前任务已经使用复用的可见保留子代理
或父代理定制的运行时新子代理完成，不轮询、不重新加载、不重启。跨任务保留只让 TOML
配置和 SQLite 所有权记录休眠存在；当前运行线程照常结束并进入 Done，不持续调用模型。
重配前已经创建的子代理线程不会因 TOML 改变而刷新提示；不得用 `followup_task` 复用旧线程
冒充新配置验证。新通信规则必须在以后新任务生成的新线程中核验。

生成的 `developer_instructions` 第一段先写角色、职责和权限，第二段才写通信规则。这个静态
结构只服务可读性；新生成线程须通过内部通道并在自身任务界面声明实际配置，但不规定它们与
reasoning、读取、分析、工具调用或真实工作之间的先后顺序。

## 存活轮次与状态查询

“存活轮次”不是模型消息数、经验事件序号或线程心跳。一次存活轮次定义为：一个正式保留
子代理，或承载其同一身份与配置的内置路线，完成一个新的当前子任务，达到父代理为本次单独
指定的成功条件，结果经父代理核验采用，并正常进入 Done。父代理在启动前生成 UUID `run_id`，
写进任务说明；上述条件全部满足后才执行：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py record-run `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --run-id <本次任务说明中的 UUID> `
  --invocation-kind spawn_agent
```

`--invocation-kind` 只接受 `spawn_agent` 或 `followup_task`。同一 `run_id`、同一代理和同一
调用类型重复提交只返回已记录，不重复计数；把同一 ID 换给其他代理或调用类型会安全拒绝。
工具缺失后停止、未达到成功条件、失败、用户否定、结果未采用或线程尚未结束都不得记录。
这是一笔组结束位置的短事务；忙锁、结构或文件身份不立即可用时跳过，不重试、不等待。

当前正式数量、磁盘 `lean_*.toml` 总数、未登记文件和每名存活轮次由只读状态命令统一报告：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py status
```

SQLite v2 以前没有稳定运行 ID；v2→v3 迁移新增空的 `agent_runs` 表，保留全部代理与经验，
但不猜测历史次数，所以现有代理的初始存活轮次为 0。存活记录是追加式审计数据；已有存活
轮次的代理不能由普通退役命令连带清空。

## 只保留有用经验

任务类型组的唯一子代理已经确定、结果通过必要核验并被采用后，自动授权为保留子代理默认
追加一条提炼、去敏、非重复且可复用的经验。来自复制和变体的多条观察先由父代理合并，只
写入一个新的原始事件；没有复制或变体的组也从自己的已采用结果提炼一条。只有没有任何新增
可复用内容或命中明确排除项时才跳过并写明原因：

用户已经表示不满意的子代理及其结果永远不能进入经验候选、原始经验或摘要。经验写入前
收到否定时立即取消本次辅助动作。若原始经验已经误提交，SQLite 的只追加约束意味着不能
伪称物理删除；使用同一 `improve` 动作追加一个指向原事件的纠正事件：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py improve `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --event-id <纠正事件唯一标识> `
  --retracts-event-id <被否定原事件唯一标识> `
  --lesson "经过重新核验、可安全复用的纠正经验"
```

纠正事件和被否定原事件都只追加保留，不能更新或删除。脚本立即从保留子代理的活跃记忆
排除被否定原事件；若现有摘要可能已经覆盖它，就使该派生摘要失效，从未受污染的活跃
事件重新形成有界窗口并返回新的压缩需要。纠正不能安全提交时，不得复用受污染的保留
子代理；主任务由父代理或新的子代理从可信输入重做，不等待经验维护。

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py improve `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --event-id <唯一标识> `
  --lesson "可复用且有证据支持的经验"
```

原始事件和纠正事件都只追加；单条经验最多 4096 个字符，但事件总数量没有上限。一个原事件
最多只能有一个纠正事件，
纠正只能指向同一保留子代理的普通原事件，不能纠正另一个纠正事件。不得记录坏结果、
原始提示、源码、仓库路径、网址、日志、凭据或模型思维过程。每次更新只读取一个有界
活跃窗口，较早原始记录保留在数据库中等待以后增量压缩。摘要同时受字符数和 UTF-8
字节数限制；完整提示不再有独立的 6 KiB 硬门槛。当前提示中的经验窗口最多 4 KiB，写入前
使用真实 TOML 序列化结果核对完整角色文件不超过 16 KiB，中文、转义字符、模型字段和快速
模式配置都计入。两个数值只是插件自身的提示成本与文件安全边界，不是用户要求或官方限制；
窗口放不下的事件仍留在 SQLite 等待摘要压缩，不截断或删除原始经验。

返回 `compaction.needed=true` 时，只有摘要压缩能与仍需完成的真实工作并行且不争用时，才让
合格且成本较低的子代理并行压缩旧摘要和增量事件；否则推迟摘要，但不撤销已经追加的原始
经验。提交摘要：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py improve `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --summary "压缩后的可复用摘要" `
  --covered-through <序号> `
  --source-digest <摘要来源哈希>
```

来源哈希和序号是比较并交换保护。刷新摘要永不删除或截断原始事件。若压缩会拖慢主
任务，直接推迟。

## 可恢复退役与恢复

运行时复制和变体在唯一子代理确定、经验维护完成或跳过后移出任务类型组并结束，通常不留
下持久文件。若插件确实持久化了同组非胜出候选，仍沿用原资格：经验已经转移、候选本身没有
原始经验、候选明确属于插件、文件身份全部匹配且用户没有撤销清理规则。最近的协作授权不
改变这项删减资格或尺度。合格候选从活跃 SQLite 登记中退役，重要角色 TOML 与可验证收据
移入 `<CODEX_HOME>/lean-stack/待删文件`；不合格候选保持原位。已有任何原始经验或存活轮次
的保留子代理仍拒绝退役，避免破坏只追加台账。唯一保留子代理、用户自有、项目自有或来源
不明的代理不属于普通候选清理。严重失败、用户否定结果、未授权影响或伪造证据只能触发停止
采用、阻止继续使用和报告风险，不能放宽退役条件：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py delete `
  --name <代理名称> `
  --expected-sha256 <当前哈希> `
  --owner-token <所有权令牌>
```

退役要求台账记录、直接普通配置路径、单一硬链接、受管标记、名称、所有权令牌和文件哈希
全部匹配；经验与存活轮次都必须为零。缺失文件的孤儿台账清理仍要求同一哈希和令牌，但没有
TOML 就不生成待删收据。辅助脚本在移动前再次核对路径、身份和哈希；目标在操作间隙发生
变化时立即跳过，不覆盖并发结果。SQLite schema 不增加退役状态；活跃行删除后，待删 TOML
和收据构成恢复证据。

成功退役返回 `action=retired_to_pending_deletion`、原路径、待删路径、收据路径、哈希和
`recoverable=true`。收据不保存 `owner_token`；恢复者必须从原有安全回执重新提供令牌和
精确哈希。可以用收据路径或唯一名称恢复，两者只选一个：

```powershell
py -3 -X utf8 .\skills\lean-stack\scripts\agents.py restore `
  --receipt <待删收据绝对路径> `
  --expected-sha256 <退役时哈希> `
  --owner-token <原所有权令牌>
```

也可以把 `--receipt` 换成 `--name <代理名称>`；名称必须在待删目录中唯一对应一份有效收据。
恢复仍核对收据、TOML、直接普通文件、单一硬链接、插件标记、身份、令牌、哈希、原始路径和
SQLite 冲突，不能借恢复接管用户文件或替换活跃角色。成功后 TOML 原子移回原路径并恢复原
活跃登记；收据不永久删除，而是不覆盖地归档到
`<CODEX_HOME>/lean-stack/待删文件/已恢复收据`。若归档发生并发冲突，已提交的恢复保持成功，
原收据保留，活跃登记的身份冲突继续阻止重放。

文件系统移动与 SQLite 不能组成单一跨资源原子事务。普通 Python 异常路径会在精确字节和
不覆盖条件成立时对称回滚；断电或强制终止仍可能在收据写入、TOML 移动、数据库提交或收据
归档之间留下可审计的中间状态。中间状态保留 TOML 或收据证据，不自动猜测或物理清除；需要
人工按台账、原路径、待删路径、收据和哈希核对后再恢复。

## 数据库边界

独立数据库位于：

```text
<CODEX_HOME>/lean-stack/specialist-memory-v1.sqlite3
```

它只保存保留子代理所有权、幂等追加的成功存活轮次、只追加经验和压缩摘要，从不打开、迁移
或删除旧生命周期数据库或旧隔离数据。只有版本为零且没有用户对象时才初始化新结构。完全
匹配的 v1/v2 经验结构可以在短事务中迁移到 v3；v2 的代理与经验全部保留，历史轮次不回填。
未知版本、意外表、
视图、触发器、命名索引、列结构、主键或唯一索引、外键、忙锁、损坏或不可用文件都
会让辅助命令关闭，但主任务继续。

结构核对维护当前规范建表定义，并直接与 SQLite 保存的结构比较，不再分别维护重复的列、
索引和外键清单。只允许完全匹配的旧版经验结构在短事务中迁移到支持纠正关系的当前结构，
所有原始事件、序号和摘要原样保留；未知版本或任何结构漂移继续拒绝。短写事务使用
`BEGIN IMMEDIATE` 和极短忙锁等待；拿不到写锁就跳过。SQLite 只服务经验侧链，不用于
